Slide 3: 1.1 Project Objectives
============================================================
1.1.1 General Objective:
- Design, develop, and deploy an AI-powered autonomous indoor surveillance robot
  that patrols a university main hall, detects human presence, and sends alerts
  during restricted hours.

1.1.2 Specific Objectives (clear and measurable):
1) Build robot platform: Raspberry Pi 4 + 4WD + ultrasonic obstacle avoidance.
2) Implement human detection in real time.
3) Train zone recognition model.
4) Implement virtual boundary detection.
5) Send SMTP alert with image and timestamp within <= 30 seconds.
6) Implement layered local-control + AI decision architecture.
7) Evaluate performance:
   - Human detection accuracy >= 85%
   - Zone recognition accuracy >= 80%
   - Patrol cycle <= 15 minutes

Slide 7: 3.6 Project Scopes and Constraints
============================================================
In scope:
- Autonomous indoor patrol
- Human detection
- Zone recognition
- Virtual boundary detection
- Obstacle avoidance
- Email alerts with image + timestamp
- Activity logging

Out of scope:
- Outdoor operation
- Facial recognition/identity verification
- Full live remote dashboard
- Full integration with all existing CCTV systems (this phase)

Quantitative requirements:
- Human detection accuracy >= 85%
- Zone recognition accuracy >= 80%
- Email alert latency <= 30 seconds
- Patrol cycle <= 15 minutes
- Processing latency <= 200 ms/frame (target)

Constraints:
- Limited budget and hardware resources
- SDP timeline limits
- WiFi dependency for email alerts
- Single-student development capacity
